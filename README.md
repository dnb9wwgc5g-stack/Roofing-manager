# Commercial Roofing Manager — MVP v3

This version adds:
- Roofing squares as the primary area unit (1 square = 100 SF)
- Roof-area measurement entry that converts SF to squares
- Visual measured-area overlays
- Daily progress snapshots
- Snapshot history on each project
- Crew-aware completion forecasting
- Projected profit
- Interactive overhead image and commercial detail markers

This remains a local browser prototype. Do not enter sensitive production data yet.
